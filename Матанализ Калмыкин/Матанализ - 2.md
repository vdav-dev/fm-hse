## Почему $\mathbb{R}$ - поле?
$(a_n), (b_n)$ - послед Коши
$a_n + b_n$ - послед Коши  $|a_n - a_m| < e/2 \quad |b_n - b_m| < e/2 \implies |a_n + b_n - a_m - b_m| < e$
$a_n \sim a_1^{'}$ $a_n + b_n - a_n^{'} - b_n^{'} = (a_n - a_n^{'}) + (b_n - b_n^{'}) = o(1) - o(1) = o(1)$
$b_n \sim b_1$
$a_n b_n$ - п-ть Коши: $a_nb_n - a_mb_m=(a_n-a_m)b_n+(b_n-b_m)a_m$
$a_nb_n = (a_n^{'} + o(1))(b_n^{'} + o(1)) = a_n^{'}b_n^{'}+a_n^{'}\cdot o(1) + b_n^{'}\cdot o(1) + o(1) \cdot o(1)$
Отсюда можно доказать аксиомы

**Лемма** $n_1 < n_2 < \dots$ - посл чисел
$a_n$ - посл-ть Коши
Тогда $a_{n_k}$ - посл-ть Коши и $a_k = a_{n_k} + o(1)$
Д-во: $\forall \epsilon>0$ при $kl > N \quad |a_k - a_l| < \epsilon$
$|a_{n_k} - a_{n_l}| < \epsilon \quad |a_{n_k}-a_k|<\epsilon$

**Следствие**
Если $\forall \epsilon> 0 \quad \exists \infty \ n: |a_n|<\epsilon$, то $a_n = o(1)$
Д-во: Выберем $n_k$ так, чтобы 
$|a_{n_k}| < 1/k$. Заметим, что $a_k = a_{n_k} +o(1) = o(1)+o(1) = o(1)$

**Существование обратного**
Пусть $a_n \neq o(1)$, т. е. $\exists$ посл-ть Коши, которая не представляет 0 (не бесконечно малая). Докажем, что ее можно обратить ($a_n \cdot b_n \to 1$)
По следствию $\exists \epsilon > 0 :$ при $n > N \quad |a_n| > \epsilon$

$|b_n = b_m| = |1/a_{n+N} - 1/a_{m + N}| = (a_{m+N} - a_{n + N}) / (|a_{n+N}||a_{m+N}|)$
$\forall \epsilon_1>0$ на достаточно больших $n, m$ $|a_{m+N} - a_{n+N}| < \epsilon_1\epsilon^2$
$|1/a_{n+N}|<1/\epsilon$
$|1/a_{m + N}| < 1/\epsilon$
$a_{n+N} = a_n + o(1)$
$a_{n+N}b_n = a_nb_n + o(1)$
